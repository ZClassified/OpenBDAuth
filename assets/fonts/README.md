# Mitgelieferte Schriften

Diese Schriften werden für alles verwendet, was OpenBDAuth **auf die Disc rendert**. Dadurch sieht
eine Disc auf jedem Rechner und Betriebssystem identisch aus, unabhängig von installierten Schriften.

| Datei | Verwendung | Quelle | Lizenz |
|---|---|---|---|
| `LiberationSans-Regular.ttf` (v2.1.5) | Menü-Buttons (metrisch identisch mit Arial) | https://github.com/liberationfonts/liberation-fonts | SIL Open Font License 1.1 (`LICENSE-LiberationSans.txt`) |
| `NotoSans-Regular.ttf` | Untertitel aus `.srt` (Latein, Griechisch, Kyrillisch) | https://github.com/notofonts/latin-greek-cyrillic | SIL Open Font License 1.1 (`LICENSE-NotoSans.txt`) |

Für Japanisch, Chinesisch und Koreanisch werden Systemschriften verwendet (siehe `modules/fonts.py`).
